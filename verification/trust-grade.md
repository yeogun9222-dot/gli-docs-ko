# Trust Grade 검증체계

> 상태: 현재 데모 원문·기획 기준입니다. 8등급별 상세 판정 세칙(인접 등급을 구별하는 필수 증빙·절차·유효기간·예외 규칙)은 아직 완성되지 않았습니다. 아래 설명 이상의 세부 기준을 추정하지 않습니다.

## 등급 체계

**S · A+ · A · B+ · B · C+ · C · D** 8단계입니다. Trust Grade는 멤버십의 정보 열람 등급(LV.1~LV.5)과는 별개의 체계입니다.

자산 유형에 따라 평가 대상이 다르므로, 부동산 자산과 프로젝트(개발) 자산의 등급 설명을 서로 바꿔 적용하지 않습니다.

## 부동산 등급별 설명

| 등급 | 설명 |
|---|---|
| S | 확인 항목이 대부분 채워짐 |
| A+ | 확인 항목이 대부분 채워짐 |
| A | 확인 항목이 대체로 채워짐 |
| B+ | 확인할 항목이 남아 있음 |
| B | 확인할 항목이 남아 있음 |
| C+ | 확인이 덜 된 항목이 많음 |
| C | 확인이 덜 된 항목이 많음 |
| D | 확인이 거의 되지 않음 |

확인되지 않은 항목은 "조사 예정"으로 표시됩니다. 평가 대상은 **객관적 자료가 얼마나 검증되었는가**입니다 (확인된 필드 비율, 자료 최신성, 출처 간 불일치 여부를 종합 — 조사량이나 치안 등은 평가에 포함되지 않습니다).

## 프로젝트(개발) 등급별 설명

| 등급 | 설명 |
|---|---|
| S | 대형 주체 · 위험 낮음 |
| A+ | 주체·절차 확인됨 |
| A | 주체·절차 확인됨 |
| B+ | 확인된 주체 · 일부 위험 |
| B | 확인된 주체 · 일부 위험 |
| C+ | 자료가 제한적 · 위험 높음 |
| C | 자료가 제한적 · 위험 높음 |
| D | 절차가 불투명 · 위험 매우 높음 |

프로젝트 등급은 **사업 주체와 계약 구조의 위험도**를 평가합니다 (주체의 규모·이력·계약 확인 여부, 계약 구조의 법적 지위, 실적 자료, 인허가·권리 확인 단계 등을 종합). 높은 수익률을 내건 주체라도 신뢰도가 낮으면 등급이 내려갑니다 — GLI는 수익률이 아니라 주체를 판정합니다.

## 알려진 한계

일부 인접 등급(예: S와 A+, B+와 B)은 현재 자료상 설명이 동일합니다. 이를 구별하는 세부 판정 세칙은 아직 확보되지 않았으므로, 등급 설명만으로 수익 보장이나 구체적인 검증 완료 항목을 추론하지 않습니다.
