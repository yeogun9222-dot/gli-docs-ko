# Trust Grade 검증체계 (AI Trust Standard)

GLI는 "AI가 넓게 찾고, 전문가가 깊게 확인합니다"를 원칙으로, AI 기반 자산 수집과 현지 전문가 실사를 결합한 검증 절차를 운영합니다. 무엇을 확인했고 무엇을 확인하지 못했는지를 함께 공개하는 것이 원칙입니다.

## 등급 체계

자산 탐색 페이지의 실제 등록 자산에서 확인된 등급 표기: **A+, A, B+, B, C** (Trust 등급 배지로 카드에 표시됨). 전체 8개 등급(S~D) 중 일부이며, 등급별 정확한 산정 기준은 아직 확인되지 않았습니다.

| 항목 | 상태 |
|---|---|
| 검증 절차 | AI 수집 + 현지 전문가 실사 결합 (확인됨) |
| 등급 체계 | 실사용 중인 등급: A+, A, B+, B, C 등 (확인됨) — 전체 S~D 8단계 세부 기준은 대기 중 |
| 세부 산정 기준 | 자료 대기 중 |

> 5단계 검증 절차의 세부 내용과 각 등급(S~D)별 정확한 산정 기준은 추가 자료 확보 후 보강 예정입니다.
