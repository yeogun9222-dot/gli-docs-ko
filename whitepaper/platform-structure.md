# 플랫폼 구조 (GLI 백서 기준)

## 3대 사업 영역

| 영역 | 내용 |
|---|---|
| Investment | 글로벌 부동산, 검증된 주거·상업 자산의 공동 소유와 배당 |
| Leisure | 리조트·트래블, 프리미엄 휴양 자산의 이용 권한과 멤버십 혜택 |
| Game | 소셜 카지노, 글로벌 게이밍 사업의 수익 배분 참여 |

## 토큰화 절차

| 단계 | 내용 |
|---|---|
| 1. Sourcing | 파트너와 함께 프리미엄 자산을 발굴하고 검증합니다 |
| 2. Structuring | SPV를 설립하고 법적 구조를 확정합니다 |
| 3. Issuance | 증권형 토큰을 발행하고 스마트 컨트랙트를 감사받습니다 |
| 4. Distribution | 마켓플레이스에서 거래하고 배당을 자동 지급합니다 |

> 본 내용은 정보 제공 목적이며 투자 권유가 아닙니다. (백서 최종 업데이트: 2026-01-05)
